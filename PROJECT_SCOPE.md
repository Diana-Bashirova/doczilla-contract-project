# Project Scope

**Проект:** Автоматизация составления договоров в платформе Doczilla  
**Статус:** Учебный проект (демонстрационный макет на синтетических данных)  
**Дата актуализации:** 11.11.2026

## Цель проекта
Демонстрация того, что типовые договоры и комплекты связанных документов могут быть подготовлены быстрее и с меньшим количеством технических ошибок благодаря управляемой автоматизации в платформе Doczilla. Приоритет отдается использованию нативных возможностей платформы, а не внешней разработке.

## В рамках проекта (In Scope)
1. Конфигурация интерактивного шаблона договора и сопутствующих документов (спецификация/приложение) в Doczilla.
2. Настройка логики документа: 30–50 переменных, условные ветвления (включая вложенные условия) и мультипликаторы для повторяющихся таблиц.
3. Разработка и версионирование (минимум 3 версии) промптов для контролируемого извлечения фактов из текста с нормализацией и строгой привязкой к идентификаторам полей (field_id).
4. Контроль качества: создание чек-листа из 15–20 правил проверки, матрицы обязательных негативных тестов (T01–T12) и расчет метрик качества.
5. Экспорт: генерация финальных документов в форматах DOCX и PDF с сохранением структуры, нумерации и перекрестных ссылок.
6. Отчетность: подготовка итогового отчета, метрик сравнения с ручным baseline и сценария демонстрации.

## За пределами проекта (Out of Scope)
1. Разработка собственной CLM/ERP/CRM-системы или внешнего веб-интерфейса.
2. Прямое программирование внутреннего ядра Doczilla или создание внешних API без согласования с куратором.
3. Автоматическая юридическая экспертиза: система не принимает правовых решений, а только извлекает факты и подсвечивает конфликты для ручного решения человеком.
4. Работа с реальными конфиденциальными договорами или персональными данными (используются исключительно синтетические данные, например, ООО "Ромашка", ИНН 7700000000).

## Согласованные параметры
| Параметр | Значение |
| :--- | :--- |
| **Команда** | 3 студента (Архитектор шаблона, AI-инженер, QA-инженер) |
| **Права доступа** | Роль «Эксперт» (без прав администратора) |
| **Объект работы** | Договор оказания IT-услуг + Приложение (спецификация) |
| **Масштаб** | ~40 переменных, 2+ типа вариативности, 1 мультипликатор, 15–20 правил чек-листа |
| **Данные** | Строго синтетические или обезличенные учебные примеры |

## Ключевая установка
Проект выполняется исключительно внутри платформы Doczilla. Главная ценность решения заключается в качестве интерактивного шаблона, контролируемом AI-заполнении и доказанной надежности проверки, а не в сложности внешних интеграций.
