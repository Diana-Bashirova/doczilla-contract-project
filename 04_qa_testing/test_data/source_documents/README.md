## Правила использования

1. Файлы являются демонстрационными учебными примерами и не содержат реальных конфиденциальных данных.
2. Запрещается модифицировать содержимое файлов без согласования с командой (это нарушит воспроизводимость тестов).
3. При добавлении новых тестовых сценариев создавать новые файлы с понятными именами (например, input_KP_04_conflict.pdf).
4. Все прогоны AI-модуля и чек-листа должны ссылаться на эти файлы как на эталонный набор.
