# Автоматизация составления договоров в Doczilla

Учебный практический проект по автоматизации подготовки типовых договоров и сопутствующих документов с использованием платформы Doczilla. Проект демонстрирует, что типовые документы можно подготовить быстрее и с меньшим количеством технических ошибок благодаря управляемой автоматизации, контролируемому AI-заполнению и доказанной надежности проверки.

## Ключевая установка
Проект выполняется исключительно внутри платформы Doczilla. Не требуется создание отдельного сервиса, собственного веб-интерфейса или внешних API. Главная ценность решения — качественный интерактивный шаблон, контролируемое извлечение данных и строгая валидация результата.

### Совместные обязанности
- Согласование единого реестра полей (field_id) и версий шаблона.
- Взаимная проверка работ и совместное тестирование (Студент 3 не является единственным исполнителем тестов).
- Подготовка итоговой демонстрации, отчета и ответов на вопросы куратора.

## Структура репозитория

- `01_business_process/` — Описание бизнес-процесса согласования (роли, этапы, правила маршрутизации).
- `02_document_template/` — Словарь данных (30–50 переменных), карточки полей, логика условий и мультипликаторов.
- `03_ai_extraction/` — Версии промптов для AI-автозаполнения, примеры маппинга данных, протокол извлечения.
- `04_qa_testing/` — Чек-лист проверок, матрица тестовых сценариев (T01–T12), синтетические тестовые данные.
- `05_integration/` — Единый реестр идентификаторов полей (field_id), трекер дефектов, регрессионные тесты.
- `06_report/` — Материалы для защиты: черновик отчета, сценарий демонстрации, скриншоты.
- `docs/` — Внутренняя документация: заметки со встреч, архитектурные решения.

## Масштаб и ограничения проекта

- **Объект работы:** Типовая форма договора оказания IT-услуг + приложение (спецификация).
- **Масштаб:** Ориентир на 30–50 переменных, условную логику (включая вложенные условия), мультипликаторы для таблиц, 15–20 правил контроля.
- **Данные:** Используются исключительно синтетические или обезличенные учебные примеры. Работа с реальными конфиденциальными договорами исключена.
- **Права доступа:** Роль «Эксперт» в Doczilla, без прав администратора.

## Статус проекта
- **Текущий этап:** Неделя 1. Анализ и проектирование.
- **Ближайшая контрольная точка:** Утверждение источников, объема данных и единого реестра полей.
